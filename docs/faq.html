FREQUENTLY ASKED QUESTIONS

Start with doctor, source, and range

Most first-run issues are visible without opening or sharing a log file.

Why does tokens say no logs were found?

Want to explore before installing or cloning? Open the hosted synthetic Demo; it needs no install or local logs.

Run from a source checkout:

./run doctor

To explore the full dashboard locally without logs, run ./run demo --open. It uses generated sample data only. By default (--source auto), tokens enables every readable source among Claude Code, Gemini CLI, Codex, OpenCode, and Antigravity; pass explicit flags to check one source at a time:

./run day --source gemini
./run day --source codex
./run day --source opencode
./run day --source antigravity

The installed CLI and the logs must also belong to the same user account unless paths are customized via environment variables.

How are OpenCode and Antigravity read?

OpenCode opens ~/.local/share/opencode/opencode.db (respecting XDG_DATA_HOME) via a read-only SQLite connection and queries only assistant-message token, model, session, directory, and timestamp fields. Antigravity reads ~/.gemini/antigravity/conversations/*.db (override via TOKENS_ANTIGRAVITY_DIR) via read-only SQLite metadata fields only (input, output, cache read, model, time, session), skipping zero-token rows and never opening conversation content or summaries; it carries no cwd and has no quota signal. Both use sqlite_wal signatures so WAL writes refresh the cache.

How accurate is quota forecasting?

Codex reads official rate_limits snapshots recorded directly in your local session logs, so its percentages and reset times are exact. Claude exposes no official percentage, so its section is an explicit estimate built from Anthropic-direct tokens inside historical 429 rate-limit windows (hits) or completed windows without a hit (safe_floor); CCR-routed backends are excluded. Because safe_floor only records the highest 5-hour direct usage you have completed without hitting a limit, it is strictly a lower bound on capacity—your actual ceiling may be higher. Likewise, a past_floor projection means your current pace would pass that historical no-limit high-water mark, not that you are guaranteed to hit a rate limit. The dashboard's Today HUD shows the same windows and highlights rows in the alert color only when projected to hit the limit before reset (or already at 100%).

Does tokens outcomes modify my git repositories, and why are recent commits pending?

No. Every git call runs in read-only mode with GIT_OPTIONAL_LOCKS=0, GIT_TERMINAL_PROMPT=0, and strict timeouts; commit messages, diffs, file paths, and author emails never leave memory. Commits younger than 7 days stay in the 7-day observation window: their added lines are counted under Pending, while survival is reported as unknown (—) rather than zero so recent work is not misread as discarded code. See CLI outcomes and git outcomes privacy.

How should I install tokens—wheel or source checkout?

Both work. Tagged releases on GitHub Releases provide a wheel, an sdist, and SHA256SUMS to verify and install into a virtual environment (0.3.0 is not published to PyPI—see Install from a GitHub Release). You can also run directly from a cloned source checkout with ./run, or install an editable tokens command inside a virtual environment with python -m pip install -e ..

Which timezone defines a day?

The detected system local timezone. Override it for a source-checkout run with an IANA name:

./run dashboard --timezone Asia/Tokyo

An unknown timezone is rejected instead of silently falling back.

Why did a changed log not update the dashboard?

An exported dashboard.html is a generation-time snapshot; refreshing the browser cannot rerun Python. Keep a live view open from the source checkout with:

./run serve --open

Live mode checks file modification time and size (plus Windows handle change times) every five minutes by default. The open page can choose another preset or pause refresh. Re-run an offline export when you need a newer archive.

How do I switch between English and Chinese?

Terminal reports and static HTML reports accept --lang en or --lang zh (defaulting to TOKENS_LANG, then your system locale). The interactive dashboard has an in-page language switch in the header that re-renders all sections, charts, and tooltips immediately and remembers your choice locally in tk-lang.

Does --open work across platforms?

It uses the Python standard library to open either a file URL or the loopback live URL in the default browser on macOS, Linux, and Windows. If opening fails, an export remains valid and a live server keeps running; the path or URL is printed.

Is an anonymized dashboard safe to publish?

Not automatically. It is pseudonymized: exact dates, models, token values, relationships, outcomes counts/ratios, and replay sequences remain. Restrict the date range and inspect the file before sharing.

Why can the dashboard be large?

It is one self-contained file with data, styles, scripts, aggregates, and retained session token sequences. A longer range and more attributable entities increase size. Use --since and --until to reduce it.

Does it contain complete message text?

Per-turn replay stores token values, not full per-turn text. A regular report can still contain a natural-language session title derived from a sidecar or suitable first user text. --anonymize skips those titles.

Still stuck?

Open an issue with the command, operating system, Python version, and sanitized error output. Do not attach raw logs or an unreviewed dashboard.
