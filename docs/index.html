Built for a private local workflow

No hosted service

There is no account, backend, telemetry collector, CDN, or external runtime request. Live mode binds only to 127.0.0.1; offline exports remain one HTML file.

Useful across tools

One interface normalizes the local formats exposed by Claude Code, Gemini CLI, and Codex while preserving source-specific totals.

Safe defaults, explicit limits

The default source is Claude, output goes to ./out, cache lives in the user cache directory, and sharing risks are documented rather than hidden.

Deep when you need it

Start with trends and model mix, then open Data Trail, project and session views, context reuse, rhythm, achievements, or Token Almanac.

Local does not mean anonymousA generated dashboard can contain paths, session identifiers, exact dates, models, and behavior patterns. Use --anonymize, restrict the date range, and inspect any file before sharing it.
