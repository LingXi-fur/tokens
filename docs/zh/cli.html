COMMAND LINE REFERENCE

一个入口，六种命令模式

PyPI 分发名是 ai-cli-tokens，安装后的命令是 tokens。

语法

tokens [day|week|month|all|dashboard|serve|doctor] [options]

统计模式

模式默认窗口聚合方式
day最近 14 天按日；默认模式，焦点为今天
week最近 8 周按周
month最近 6 个月按月
all全部历史按日
dashboard筛选后的全部记录导出可离线打开的日 / 周 / 月快照
serve筛选后的全部记录启动仅绑定本机回环地址的实时 Dashboard
doctor不读取记录内容检查来源、候选文件、时区、输出和缓存目录

参数

参数类型 / 默认说明
--sinceYYYY-MM-DD起始日期；提供后覆盖模式默认起点。
--untilYYYY-MM-DD / 今天结束日期。
--days正整数 / 14day 模式回看天数。
--weeks正整数 / 8week 模式回看周数。
--months正整数 / 6month 模式回看月数。
--source可重复限定 claude、gemini、codex；默认仅 claude。
--output DIR./out选择报告输出目录。
--timezone AREA/CITY系统本地时区使用 IANA 时区解释日期和小时。
--html开关在终端报告之外生成单期静态 HTML。
--dashboard开关生成交互式 Dashboard；等价于位置模式 dashboard。
--anonymizeDashboard 开关在离线或实时 Dashboard 中以服务 / 报告生命周期内稳定的别名替换项目路径、会话标识和自然语言标题。
--interval SECONDS秒 / 5实时模式检查间隔，最小为 1。
--port PORT端口 / 8765实时模式本机回环端口；传 0 由系统选择可用端口。
--open开关用系统默认浏览器打开生成文件或本机实时 URL。
--no-cache开关忽略文件缓存，强制重读日志。
--version开关输出当前版本。

示例

终端报告

tokens
tokens week
tokens month --months 12
tokens all

多来源

tokens day --source claude --source gemini
tokens month --source codex

精确日期范围

tokens day --since 2026-01-01 --until 2026-03-31
tokens dashboard --since 2026-01-01 --until 2026-12-31

Dashboard

tokens serve --open
tokens serve --port 0 --interval 2
tokens dashboard
tokens dashboard --anonymize
tokens --dashboard --open

行为说明

  • 默认使用系统本地时区；可用 --timezone Asia/Shanghai 等 IANA 名称显式覆盖。
  • 如果没有读到记录，命令返回状态码 1，并提示运行 tokens doctor。
  • 普通模式始终先输出终端报告；只有指定 --html 才额外写文件。
  • 离线 Dashboard 保留日期与来源筛选，并在生成文件内提供日 / 周 / 月切换。
  • 实时模式只绑定 127.0.0.1，默认每 5 分钟先比较文件修改时间与大小；页面可选择 1、5、15、30 分钟或暂停，未变化时不重新解析或传输。
  • 实时模式可以在初始没有记录时继续等待；按 Ctrl+C 停止。
  • --anonymize 只接受 Dashboard 或实时模式；它保留精确日期、Token、模型、匿名关系与匿名会话回放，因此是假名化而不是完全匿名。
  • 报告默认写入当前工作目录下的 out/；缓存写入平台用户缓存目录，与报告分离。
不要把 --open 当成生成条件它只控制生成后是否自动打开。自动化与回归测试中建议省略，避免启动 GUI。
