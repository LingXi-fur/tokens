本机实时数据宇宙

tokens serve 通过仅绑定 127.0.0.1 的本机服务自动更新；tokens dashboard 则把同一界面导出为可离线打开的单个 HTML。

安装前先体验打开完整交互式合成 Dashboard。页面仅使用生成的示例数据，不读取访客设备上的任何日志。

打开本机实时 Dashboard

tokens serve --open
tokens serve --since 2026-01-01 --source claude
tokens serve --anonymize

服务只绑定 127.0.0.1，由单个后台 worker 按默认 300 秒周期扫描日志签名。首页与 API 直接读取最近一次成功的内存快照，不等待下一次扫描。浏览器默认最多每 60 秒检查一次发布状态，准备或扫描进行中则为每 1 秒；页面下拉的 1、5、15、30 分钟或暂停只改变浏览器轮询，不影响后台扫描。初始准备不展示占位 0，后续扫描失败时保留旧统计并显示上次成功检查时间。签名未变化时不重新解析。只有已发布响应版本未变化且没有扫描错误时，条件请求才返回 304；成功检查可以推进响应版本，而不改变统计快照。报告数据变化时，后台复用文件缓存、发布新快照，页面无需整页刷新即可更新。

导出离线快照

tokens dashboard --open
tokens dashboard --anonymize

原始输出路径为 out/dashboard.html；脱敏输出为独立的 out/dashboard-anonymized.html。离线文件是生成时快照，之后新增的日志不会自动进入其中。

核心分析与联动

日 / 周 / 月粒度与中英切换

标签页切换三种聚合；柱图、KPI、环形图、明细与部分模块随状态联动。柱图支持 Tab 进入、方向键检查周期和 Enter 回看；下方数据时刻轨道把事件映射到日 / 周 / 月，同周期事件自动合并，标记也支持方向键与 Enter / Space。页头提供页面内中英语言切换按钮（本地记住在 tk-lang），切换后一次性重渲染全部区块、SVG 与悬停提示，英文界面统一使用 K/M/B 与英文月份。

模型筛选

模型 chip 使用普通复选交互；筛选台账提供覆盖率、全选、清空和单步撤销。不依赖双击、右键或 Alt 点击等隐藏手势。

Signal Dock · 信号坞

悬停或键盘聚焦模型、周期、项目与会话会临时预览兼容模块；点击或 Enter / Space 可固定信号。统一面板提供“只看此模型”、进入时光探针、打开项目透镜或会话回放等上下文动作。

时光探针

点击柱子聚焦某一期，重算局部 KPI、作息、Top 项目与会话；周期固定复用同一个探针，不建立第二套周期锁。探针内可直接启动数据寻迹，Esc 返回全景。

按住对比

按住趋势按钮约 240ms，或按住 C，临时叠加上一期轮廓与变化百分比；短按按钮才固定 / 取消对比。只有固定状态进入视图 URL。

Exactness Key · 精确层

按住 Alt / Option 临时显露精确 Token、分子 / 分母、调用记录、上一期绝对与百分比变化，以及回放保留边界；也可在 Signal Dock 中固定精确层。

KPI 与预测

总量、缓存命中及缓存 Token 读取量、调用记录数、模型数、主力模型、环比和月末预测。总量保持稳定紧凑表达，精确值通过精确层和显式复制按钮访问。

Top 构成与回放

Top 从完整日级实体按当前模型筛选重新聚合，并移除筛选后为 0 Token 的条目；项目与会话行支持悬停 / 聚焦预览和点击 / Enter 固定到 Signal Dock，再从统一面板打开项目透镜或会话回放。回放展示完整会话总 Token 序列，不是当前模型筛选后的序列，每会话最多保留最近 200 轮。Top 项目 / 会话区块默认折叠，从区域导航跳到 Top 或点击区块标题时才展开。

变化归因 · 等长 A/B 时段

点击 ⇄ 比较两个时段 依次选择 A 起止与等长的 B 起点（B 必须在 A 之后且周期连续），变化归因卡便按模型拆解 A → B 的 Token 差异。选中只需点击、拖刷或聚焦柱子后按 Enter；清除选区即回到单期归因。

峰值剖面

打开 Token 最高的完整周期，查看该期总量、相邻完整前期的差值（无可比前一期时明确说明）、模型构成、记录中最忙的小时与保留的项目证据。它只呈现已记录的聚合，不判定为异常或故障，项目列表也可能只包含保留的部分项目。

Other 透明拆解与独立色槽

最多 8 个独立模型各占固定分类色（每个活跃来源至少保底 1 个模型），Other 改用中性灰。Model mix 图例、趋势图例、环形图切片、趋势悬停提示及“更多模型”下拉筛选都会逐个列出被折叠的模型及其来源、精确 Token 与占比；周期明细表点击 Other (N) 可展开成单模型子列（CSV / Markdown 导出也会直接逐个列出）；Today HUD 的主力模型永远显示真实模型名。

本地费用账本与月度预算

按独立计费分量结合内置官方 USD 参考价（GLM 与 Gemini 已于 2026-11-19 对照官网复核，连同 OpenAI、Anthropic、DeepSeek、Moonshot；官网未公布的分量留空不推算）或仅存本机浏览器（tk-cost-v1）的手填单价进行估算，并支持本地月度预算跟踪（tk-budget-v1）。费用结果为参考估算，非渠道实际扣费。

口径说明与后端标签

快照页眉标出报告范围最近记录的后端，罕见名称会归入“其他”。口径说明逐条写明数字不代表什么：六个小时桶不是计费窗口，缓存命中率不是货币节省估算，覆盖率分母是当前粒度下的全模型总量（时光探针不会缩小它）。模型名按日志原样保留。

概览洞察与可读环比

由纯计算核心 insight_core.js 驱动的三块洞察：配速赛道（今日 vs 昨日同一时刻进度，附 7 日同时刻均值与按昨日曲线形状推算的全天预测）、每日模型用量中的模型份额流（7 日居中平滑，支持份额/流模式），以及活动日历。当昨日同时刻或上期基线为 0 或不到当前的 1% 时，浮窗、节奏卡、趋势卡和复制摘要直接显示“昨日此时几乎没有用量”，不再输出失真的极大百分比；超过 +999% 的涨幅改用倍数显示（如 12.5×）。

模型对比 · 谁最划算

模型对比 · 谁最划算卡片位于深挖区，默认折叠（展开状态记在本地 tk-dig-v1），与 tokens outcomes 复用同一套只读 git 投入产出管线，可在按模型和按工具两种视图间切换。

  • 列字段：名称、会话、花费、提交、新增、已定案留存、待定、每 $1 留存、返工税。
  • 按花费占比分摊：花费按会话内各模型 / 工具的实际用量精确拆分；提交、新增、已定案留存、待定（不满 7 天）与返工税按该行在会话花费中的占比分摊（仅当会话内所有可估价金额都为 0 时改用 token 占比）。同一会话可出现在多行；不属于任何会话的手工提交不计入。
  • 排名与低样本保护：按每 $1 已定案留存行排序（尚无已定案数据时显示 —）。少于 3 个会话或已定案花费低于 $1 的行带 样本少 徽章并排在排名之外。

暗色默认、玻璃外壳与今日浮窗（Today HUD）

暗色默认与柔和浅色

Dashboard 默认采用暗色主题；浅色改为柔和低亮度的暖灰表面（峰值表面亮度约 85% 白色，正文字色仍满足 WCAG AA 对比度）。可通过 URL 参数 ?t=light、?t=dark 或 ?t=auto 指定主题；视图链接仅在偏离默认暗色时才写入 t=。

玻璃外壳与降级

半透明磨砂玻璃仅用于导航条、浮层、提示与今日浮窗等“外壳”，图表卡片保持不透明，已验证的数据配色不变。在系统开启 prefers-reduced-transparency 或浏览器不支持 backdrop-filter 时自动退回不透明表面。

Today HUD · 今日浮窗

默认位于右下角的可拖动、可折叠今日小浮窗，复用总览与配速赛道口径显示今日 Token、调用次数、主力模型、昨日同时刻对比以及订阅额度燃尽预测行。支持鼠标拖动、点击折叠、Esc 折叠与方向键微调位置；仅在本地（tk-hud-v1）记住位置与折叠状态。滚动到概览 KPI 区可见时自动让开；手机窄屏上置于左下角并默认折叠。

今日浮窗里的额度燃尽预测

当存在本地 Codex 或 Claude 额度数据时，今日浮窗按窗口各展示一行，与 tokens quota 保持同一口径：窗口名称、来源徽章（Codex 标 官方，取自本地日志中的官方 rate_limits 快照；Claude 5h 标 估算，取自历史未撞限安全窗口下限与 429 撞线样本估算，速度均按最近一小时计算）、已用百分比细条、按报告时区显示的重置时间（重置 …）与预测文案。tokens serve 随每次实时快照更新，静态导出则保留生成时的快照。

Data Trail · 数据寻迹

数据寻迹是一条非模态、可随时退出的证据轨道，用来把当前范围与已经存在的详细模块连接起来；它不会替代模块直接入口，也不会把 Dashboard 变成必须逐步完成的向导。

1 · 当前范围

确认日 / 周 / 月粒度、时光探针范围、模型覆盖、Token 与调用记录数。上一期指同粒度中紧邻的上一条可用聚合记录；没有可比较记录时明确显示“无可比较上一期”。

2 · 模型线索

临时模型只决定当前证据线，不会静默修改全局筛选。只有用户明确点击“只看此模型”时，才会调用既有模型筛选并联动整页。

3 · 平行证据

项目、会话与 Context 分别按当前范围和临时模型聚合。项目与会话保持分离，不构造或暗示项目 → 会话配对；字段不足时显示数据可信度能力原因，而不是把缺失解释为零。

4 · 深入模块

项目进入项目透镜；会话打开报告内实际保留的完整会话回放；Context 进入 Reuse River，并保留 Fresh Input、Output、Cache Read、Cache Write、Other 五分量。

语义与状态边界Token 增加 / 减少只是中性变化，不代表更好或更差；“调用记录”不等于供应商计费请求；Cache Read 是缓存 Token 量，不是已确认的货币节省；Other 是标准化分量与来源 total 对齐后的剩余量，非零时不会隐藏。会话回放不按寻迹模型或探针周期二次裁剪，每会话最多保留最近 200 轮。步骤、临时模型、分支和实体选择只存在于当前页面内存，不写入 URL、localStorage、成就快照或 Token 年鉴。

数据探索与可视化模块

  • 当前视图胶囊：持续显示粒度、模型筛选、时光探针和幻影对比状态；可恢复全景，或复制只包含非敏感 UI 状态的视图链接。
  • 数据可信度实验室：展示已解析记录中的时间戳、项目、会话和标准化 Token 组成字段可用性，并按来源列出跳过文件数与原因（区分完全损坏、部分损坏和空文件；解析器拒绝的原始事件不在分母）。回放单独显示“实际保留 / 可归属记录”，并注明每个会话最多保留最近 200 轮。顶部新鲜度信标区分刚刚同步、近期、历史和显式范围快照；复制体检摘要不包含 cwd、session 或逐轮 Token 明细。
  • 数据时刻注释轨道：范围末端静默 / 连续活跃状态进入 Signal Dock，累计 Token 里程碑、范围内首次观察项目和连续自然日的唯一主力模型变化保留在趋势注释轨道；安静日、日期缺口和并列主力会打断接力。独立 Data Moments 卡片已移除，避免重复占据页面。
  • Token 年鉴：将日级数据按自然月与至少 7 个连续静默日划分为个人赛季，以稳定星位展示身份无关的个人纪录，并在同一浏览器打开后续不同快照时生成用户控制的数据时间胶囊。第一次打开只建立基线；新纪录只与本设备此前快照比较，不是全球稀有度。年鉴历史可导出 JSON 或单独清除，不保存 cwd、session、标题或逐轮 Token。
  • 生成时刻前六个小时桶与近 14 天：展示生成时刻所在小时及往前五个小时，共六个小时桶；同时保留连续 14 个自然日，没有活动的日期显示为空白。
  • 作息织锦与状态画像：14 天 × 24 小时时间纹理、状态脉搏和本地作息画像；织锦支持方向键逐格检查，Enter / Space 回看有数据日期。
  • 工作模式图鉴：根据当前筛选后的本地聚合识别可解释活动模式，并展示判定依据；它不调用 AI，也不表示生产力排名。
  • 项目透镜：选择项目查看日 / 周 / 月模型堆叠趋势、当前占比、活跃期、峰值期、范围内首次观察与主力模型；响应全局模型筛选和时光探针，并提供可访问明细表。脱敏报告自动使用项目别名，不推断不存在的项目 → 会话关系。
  • Context Reuse River：把 Fresh Input、Output、Cache Read、Cache Write 与 Other 按时间堆叠，分量严格回归来源报告 total；支持模型筛选、时光探针和键盘逐期检查。
  • 用量去向（Token destinations）：桌面端以两栏展示——左侧为项目 / 模型概览（来自真实 project_model 记录），右侧为宽幅会话卡；手机端改为纵向堆叠，不再需要 900px 横向滚动。模型按钮在本地筛选会话，“全部模型”可重置；项目仅提供 Signal Dock 与数据寻迹入口，不推断项目 → 会话配对。会话每页 12 条，带页码与页外 Token 汇总；表格视图展示全量会话并支持独立回放动作。SVG 导出覆盖当前页、当前筛选与当前主题，不宣称包含全部会话。
  • 成就中心：以最近解锁 Hero、报告范围内达成时间线、三个最接近目标与收藏阶位摘要替代随机徽章轮播；可重建日期表述为“本报告范围内首次达到”，范围首日已满足或无法从聚合快照还原时会明确说明。青铜 / 白银 / 黄金 / 彩钻和“该阶梯前 X% 门槛”只表示本地图鉴门槛位置，不是全球用户稀有度。首次打开只建立本设备观察基线，后续新快照才会提示新观察到的成就；完整图鉴继续支持搜索、筛选、分类折叠和键盘可访问详情。
  • 模块开关：按需隐藏作息、数据可信度、项目透镜、用量去向、成就等模块，并在 localStorage 记忆；原生复选框支持键盘操作。

分享前的隐私检查

原始 Dashboard 不只是匿名统计图out/dashboard.html 会嵌入完整日级项目与会话聚合实体，而不只是页面最终显示的 Top：项目实体可保留完整 cwd，会话实体与回放会保留会话标识，标题由本地保守清洗续接 / 系统首行得到，缺标题时显示为未命名并附记录中的项目、来源与活动日期，不生成 AI 摘要。Data Trail 与 Signal Dock 会从这些既有实体中派生证据和交互上下文；页面离线或交互状态短暂，都不意味着其中的数据适合公开。即使页面不联网，这些内容也会随 HTML 一起分发。

标识脱敏版本

tokens dashboard --anonymize 会在聚合进入 payload 前，用本次报告内稳定的 Project-… 与 Session-… 别名替换项目路径和会话标识，并完全跳过会话标题文本读取；内嵌的投入产出（outcomes）区块也会同步替换项目与会话别名，并沿用图表模型归并折叠 Other 原名。Top、用量去向、数据寻迹、Signal Dock 和逐轮回放仍可使用匿名 identity 联动。

Data Trail 与 Signal Dock 都不新增持久化实体状态：寻迹步骤、临时模型、证据分支、透镜预览 / 固定信号，以及项目 / 会话选择不会进入视图 URL 或 localStorage，也不会写入成就与年鉴历史。Exactness Key 与按住对比同样只存在于页面内存；只有用户短按后固定的幻影对比会进入视图 URL。用量去向只使用真实的项目 → 模型与模型 → 会话聚合，不从两段关系推断项目 → 会话配对。上述限制只约束浏览器状态，不会从已生成的原始 payload 中删除项目、会话或回放数据。

假名化，不是完全匿名脱敏版本仍保留精确日期、Token、小时分布、模型、来源和逐轮 Token 序列。这些信息可能形成行为指纹；自定义模型名也可能带有组织或项目语义。公开发布前仍应使用受限日期范围并检查文件。
