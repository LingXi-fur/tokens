本机实时数据宇宙

tokens serve 通过仅绑定 127.0.0.1 的本机服务自动更新；tokens dashboard 则把同一界面导出为可离线打开的单个 HTML。

打开本机实时 Dashboard

tokens serve --open
tokens serve --since 2026-01-01 --source claude
tokens serve --anonymize

服务只绑定 127.0.0.1，默认每 5 秒检查安全文件签名。日志未变化时不重复解析、聚合或传输；变化后复用文件缓存，并仅在报告快照实际变化时热更新当前页面。语言、主题、模型筛选、滚动位置、Token 伙伴外观和当前页面内的参考图不会因整页重载而丢失。

导出离线快照

tokens dashboard --open
tokens dashboard --anonymize

原始输出路径为 out/dashboard.html；脱敏输出为独立的 out/dashboard-anonymized.html。离线文件是生成时快照，之后新增的日志不会自动进入其中。

核心分析与联动

日 / 周 / 月粒度

标签页切换三种聚合；柱图、KPI、环形图、明细与部分模块随状态联动。柱图支持 Tab 进入、方向键检查周期和 Enter 回看；下方数据时刻轨道把事件映射到日 / 周 / 月，同周期事件自动合并，标记也支持方向键与 Enter / Space。

模型筛选

模型 chip 使用普通复选交互；筛选台账提供覆盖率、全选、清空和单步撤销。不依赖双击、右键或 Alt 点击等隐藏手势。

Signal Lens · 信号透镜

悬停或键盘聚焦模型、周期、项目与会话会临时预览兼容模块；点击或 Enter / Space 可固定信号。统一面板提供“只看此模型”、进入时光探针、打开项目透镜或会话回放等上下文动作。

时光探针

点击柱子聚焦某一期，重算局部 KPI、作息、Top 项目与会话；周期固定复用同一个探针，不建立第二套周期锁。探针内可直接启动数据寻迹，Esc 返回全景。

按住对比

按住趋势按钮约 240ms，或按住 C，临时叠加上一期轮廓与变化百分比；短按按钮才固定 / 取消对比。只有固定状态进入视图 URL。

Exactness Key · 精确层

按住 Alt / Option 临时显露精确 Token、分子 / 分母、调用记录、上一期绝对与百分比变化，以及回放保留边界；也可在 Signal Lens 中固定精确层。

KPI 与预测

总量、缓存命中及缓存 Token 读取量、调用记录数、模型数、主力模型、环比和月末预测。总量保持稳定紧凑表达，精确值通过精确层和显式复制按钮访问。

Top 构成与回放

Top 从完整日级实体按当前模型筛选重新聚合，并移除筛选后为 0 Token 的条目；项目与会话行支持悬停 / 聚焦预览和点击 / Enter 固定到 Signal Lens，再从统一面板打开项目透镜或会话回放。回放展示完整会话总 Token 序列，不是当前模型筛选后的序列，每会话最多保留最近 200 轮。

Data Trail · 数据寻迹

数据寻迹是一条非模态、可随时退出的证据轨道，用来把当前范围与已经存在的详细模块连接起来；它不会替代模块直接入口，也不会把 Dashboard 变成必须逐步完成的向导。

1 · 当前范围

确认日 / 周 / 月粒度、时光探针范围、模型覆盖、Token 与调用记录数。上一期指同粒度中紧邻的上一条可用聚合记录；没有可比较记录时明确显示“无可比较上一期”。

2 · 模型线索

临时模型只决定当前证据线，不会静默修改全局筛选。只有用户明确点击“只看此模型”时，才会调用既有模型筛选并联动整页。

3 · 平行证据

项目、会话与 Context 分别按当前范围和临时模型聚合。项目与会话保持分离，不构造或暗示项目 → 会话配对；字段不足时显示数据可信度能力原因，而不是把缺失解释为零。

4 · 深入模块

项目进入项目透镜；会话打开报告内实际保留的完整会话回放；Context 进入 Reuse River，并保留 Fresh Input、Output、Cache Read、Cache Write、Other 五分量。

语义与状态边界Token 增加 / 减少只是中性变化，不代表更好或更差；“调用记录”不等于供应商计费请求；Cache Read 是缓存 Token 量，不是已确认的货币节省；Other 是标准化分量与来源 total 对齐后的剩余量，非零时不会隐藏。会话回放不按寻迹模型或探针周期二次裁剪，每会话最多保留最近 200 轮。步骤、临时模型、分支和实体选择只存在于当前页面内存，不写入 URL、localStorage、成就快照或 Token 年鉴。

数据探索与可视化模块

  • 当前视图胶囊：持续显示粒度、模型筛选、时光探针和幻影对比状态；可恢复全景，或复制只包含非敏感 UI 状态的视图链接。
  • 数据气候与数据侦探：根据近况、缓存、夜间比例和峰值生成本地规则描述，不调用 AI。
  • 数据可信度实验室：展示已解析记录中的时间戳、项目、会话和标准化 Token 组成字段可用性；解析器拒绝的原始事件不在分母。回放单独显示“实际保留 / 可归属记录”，并注明每个会话最多保留最近 200 轮。顶部新鲜度信标区分刚刚同步、近期、历史和显式范围快照；体检摘要不包含 cwd、session 或逐轮 Token 明细。
  • 数据时刻注释轨道：范围末端静默 / 连续活跃状态进入 Signal Lens，累计 Token 里程碑、范围内首次观察项目和连续自然日的唯一主力模型变化保留在趋势注释轨道；安静日、日期缺口和并列主力会打断接力。独立 Data Moments 卡片已移除，避免重复占据页面。
  • Token 年鉴：将日级数据按自然月与至少 7 个连续静默日划分为个人赛季，以稳定星位展示身份无关的个人纪录，并在同一浏览器打开后续不同快照时生成用户控制的数据时间胶囊。第一次打开只建立基线；新纪录只与本设备此前快照比较，不是全球稀有度。年鉴历史可导出或单独清除，不保存 cwd、session、标题或逐轮 Token。
  • 5 小时计费窗口与近 14 天：展示生成时刻前六个小时桶和连续 14 个自然日；没有活动的日期保留为空白。
  • 作息时钟与作息织锦：24 小时径向分布，以及 14 天 × 24 小时时间纹理；织锦支持方向键逐格检查，Enter / Space 回看有数据日期。
  • 趣味换算与今日运势：将总量映射到文字量级，并按本地统计生成娱乐性指标。
  • 项目透镜：选择项目查看日 / 周 / 月模型堆叠趋势、当前占比、活跃期、峰值期、范围内首次观察与主力模型；响应全局模型筛选和时光探针，并提供可访问明细表。脱敏报告自动使用项目别名，不推断不存在的项目 → 会话关系。
  • Context Reuse River：把 Fresh Input、Output、Cache Read、Cache Write 与 Other 按时间堆叠，分量严格回归来源报告 total；支持模型筛选、时光探针和键盘逐期检查。
  • Token 流光图：按真实聚合展示项目 → 模型 → 会话的 Token 流向；光带宽度对应 Token 量，悬停或键盘聚焦可预览真实关联，点击固定到 Signal Lens，再从统一面板打开项目透镜、只看模型或进入会话回放。项目与会话仍是平行实体，不从两段关系推断项目 → 会话配对；当前视图可保存为 SVG。
  • Token 生物：由总量、模型、项目、缓存与作息塑形，可保存为 SVG。
  • 柱图竞赛：按日播放模型累计 token 排名变化。
  • 成就中心：以最近解锁 Hero、报告范围内达成时间线、三个最接近目标与收藏阶位摘要替代随机徽章轮播；可重建日期表述为“本报告范围内首次达到”，范围首日已满足或无法从聚合快照还原时会明确说明。青铜 / 白银 / 黄金 / 彩钻和“该阶梯前 X% 门槛”只表示本地图鉴门槛位置，不是全球用户稀有度。首次打开只建立本设备观察基线，后续新快照才会提示新观察到的成就；完整图鉴继续支持搜索、筛选、分类折叠和键盘可访问详情。
  • Token 星云：以小时、模型和缓存构造 SVG 数据深空，可单独收藏。
  • 模块开关：按需隐藏作息、数据可信度、项目透镜、趣味、流光图、生物、成就等模块，并在 localStorage 记忆；原生复选框支持键盘操作。

分享前的隐私检查

原始 Dashboard 不只是匿名统计图out/dashboard.html 会嵌入完整日级项目与会话聚合实体，而不只是页面最终显示的 Top：项目实体可保留完整 cwd，会话实体与回放会保留会话标识，并可能采用本地 sidecar 摘要或首条提问生成标题。Data Trail 与 Signal Lens 会从这些既有实体中派生证据和交互上下文；页面离线或交互状态短暂，都不意味着其中的数据适合公开。即使页面不联网，这些内容也会随 HTML 一起分发。

标识脱敏版本

tokens dashboard --anonymize 会在聚合进入 payload 前，用本次报告内稳定的 Project-… 与 Session-… 别名替换项目路径和会话标识，并完全跳过 sidecar 摘要和会话文本标题读取。Top、流光图、数据寻迹、Signal Lens 和逐轮回放仍可使用匿名 identity 联动。

Data Trail 与 Signal Lens 都不新增持久化实体状态：寻迹步骤、临时模型、证据分支、透镜预览 / 固定信号，以及项目 / 会话选择不会进入视图 URL 或 localStorage，也不会写入成就与年鉴历史。Exactness Key 与按住对比同样只存在于页面内存；只有用户短按后固定的幻影对比会进入视图 URL。Flow 只使用真实的项目 → 模型与模型 → 会话聚合，不从两段关系推断项目 → 会话配对。上述限制只约束浏览器状态，不会从已生成的原始 payload 中删除项目、会话或回放数据。

假名化，不是完全匿名脱敏版本仍保留精确日期、Token、小时分布、模型、来源和逐轮 Token 序列。这些信息可能形成行为指纹；自定义模型名也可能带有组织或项目语义。公开发布前仍应使用受限日期范围并检查文件。
