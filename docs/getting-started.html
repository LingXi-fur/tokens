快速开始

GETTING STARTED

从日志到第一份报告

不需要数据库、服务进程或前端构建。准备好 Python 后，直接在项目目录运行。

运行要求

  • Python 3.9 或更高版本。
  • macOS 或 POSIX Linux；项目元数据暂未声明 Windows 支持。
  • 至少安装并使用过一个受支持的 CLI，使本地存在日志。
默认行为未传 --source 时仅扫描 Claude 日志。Gemini 与 Codex 需要显式开启。

安装

直接运行

git clone <repository-url>
cd tokens
python3 cli.py month

仓库中的 run 也可作为便捷入口，例如 ./run month。

安装全局命令

pipx install .
tokens month

pyproject.toml 注册的命令入口为 tokens = cli:main。

首次运行

python3 cli.py

默认进入 day 模式，聚合最近 14 天并将今天作为焦点。终端报告会显示各期总量、模型列与调用次数。

如果输出“未找到任何日志”，请确认日志目录存在，或按实际来源添加参数：

python3 cli.py day --source claude
python3 cli.py week --source gemini
python3 cli.py month --source codex
python3 cli.py all --source claude --source gemini --source codex

生成报告

单期静态 HTML

python3 cli.py month --html

文件写入 out/report-month-<焦点日期>.html，包含 KPI、总量趋势、模型/来源分布和明细表。

交互式 Dashboard

python3 cli.py dashboard

也可写成 python3 cli.py --dashboard。输出为 out/dashboard.html，数据、CSS、JavaScript 与 SVG 渲染逻辑均内嵌，离线可用。若希望系统打开文件，可额外加 --open；自动打开当前通过 macOS 的 open 命令实现。

筛选数据

python3 cli.py --since 2026-07-01 --until 2026-07-25
python3 cli.py week --source gemini --source codex
python3 cli.py dashboard --since 2026-01-01 --source claude
python3 cli.py day --no-cache

--since 与 --until 接受 YYYY-MM-DD。Dashboard 会遵守日期和来源筛选；日/周/月切换在生成文件内进行。

本地预览文档

本站是零构建静态文件。可以直接打开 docs/index.html，也可用 Python 启动本地 HTTP 服务：

python3 -m http.server 8000 --directory docs

然后访问 http://localhost:8000/。下一步可查看完整 CLI 参考或Dashboard 功能。
