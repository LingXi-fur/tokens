Dashboard

生成合成演示核心分析探索模块导出与分享快捷键隐私
SELF-CONTAINED INTERACTIVE REPORT

离线数据宇宙

Dashboard 把聚合数据、样式、交互和内联 SVG 封装在单个 HTML 中。它不请求 CDN，也不需要本地服务器。

生成

python3 cli.py dashboard
python3 cli.py --dashboard --since 2026-01-01 --source claude
python3 cli.py dashboard --anonymize

原始输出路径为 out/dashboard.html。使用 --anonymize 时会生成独立的 out/dashboard-anonymized.html，不会覆盖原始报告。位置模式与 --dashboard 开关都进入同一生成流程；传入的日期与来源筛选会写进 payload。

核心分析与联动

日 / 周 / 月粒度

标签页切换三种聚合；柱图、KPI、环形图、明细与部分模块随状态联动。柱图支持 Tab 进入、方向键检查周期和 Enter 回看；下方数据时刻轨道把事件映射到日 / 周 / 月，同周期事件自动合并，标记也支持方向键与 Enter / Space。

模型筛选

模型 chip 支持点击开关、双击单独查看、Alt 点击全选/清空、右键反选；筛选台账另提供覆盖率、全选、清空和单步撤销。

时光探针

点击柱子聚焦某一期，重算局部 KPI、作息、Top 项目与会话；Esc 返回全景。

幻影对比

在当前柱图叠加上一期轮廓与变化百分比，同时显示均值线和峰值标识。

KPI 与预测

总量、缓存命中及省量、调用次数、模型数、主力模型、环比和月末预测。

Top 构成与回放

Top 从完整日级实体按当前模型筛选重新聚合，并移除筛选后为 0 Token 的条目；会话行可用 Enter 回放。回放展示完整会话总 Token 序列，不是当前模型筛选后的序列，每会话最多保留最近 200 轮。

数据探索与可视化模块

  • 当前视图胶囊：持续显示粒度、模型筛选、时光探针和幻影对比状态；可恢复全景，或复制只包含非敏感 UI 状态的视图链接。
  • 数据气候与数据侦探：根据近况、缓存、夜间比例和峰值生成本地规则描述，不调用 AI。
  • 数据可信度实验室：展示已解析记录中的时间戳、项目、会话和标准化 Token 组成字段可用性；解析器拒绝的原始事件不在分母。回放单独显示“实际保留 / 可归属记录”，并注明每个会话最多保留最近 200 轮。顶部新鲜度信标区分刚刚同步、近期、历史和显式范围快照；体检摘要不包含 cwd、session 或逐轮 Token 明细。
  • Data Moments 数据时刻：以文本卡片和趋势注释轨道提取范围末端静默 / 连续活跃、本报告范围累计首次达到的 Token 里程碑、范围内首次观察项目，以及连续自然日的唯一主力模型变化；安静日、日期缺口和并列主力会打断接力。点击可切到按日并进入对应时光探针。
  • Token 年鉴：将日级数据按自然月与至少 7 个连续静默日划分为个人赛季，以稳定星位展示身份无关的个人纪录，并在同一浏览器打开后续不同快照时生成用户控制的数据时间胶囊。第一次打开只建立基线；新纪录只与本设备此前快照比较，不是全球稀有度。年鉴历史可导出或单独清除，不保存 cwd、session、标题或逐轮 Token。
  • 5 小时计费窗口与近 14 天：展示生成时刻前六个小时桶和连续 14 个自然日；没有活动的日期保留为空白。
  • 作息时钟与作息织锦：24 小时径向分布，以及 14 天 × 24 小时时间纹理；织锦支持方向键逐格检查，Enter / Space 回看有数据日期。
  • 趣味换算与今日运势：将总量映射到文字量级，并按本地统计生成娱乐性指标。
  • 项目透镜：选择项目查看日 / 周 / 月模型堆叠趋势、当前占比、活跃期、峰值期、范围内首次观察与主力模型；响应全局模型筛选和时光探针，并提供可访问明细表。脱敏报告自动使用项目别名，不推断不存在的项目 → 会话关系。
  • Context Reuse River：把 Fresh Input、Output、Cache Read、Cache Write 与 Other 按时间堆叠，分量严格回归来源报告 total；支持模型筛选、时光探针和键盘逐期检查。
  • Token 流光图：按真实聚合展示项目 → 模型 → 会话的 Token 流向；光带宽度对应 Token 量，悬停或键盘聚焦可追踪链路，项目和模型可锁定，会话可进入逐轮回放，当前视图可保存为 SVG。
  • Token 生物：由总量、模型、项目、缓存与作息塑形，可保存为 SVG。
  • 柱图竞赛：按日播放模型累计 token 排名变化。
  • 成就中心：以最近解锁 Hero、报告范围内达成时间线、三个最接近目标与收藏阶位摘要替代随机徽章轮播；可重建日期表述为“本报告范围内首次达到”，范围首日已满足或无法从聚合快照还原时会明确说明。青铜 / 白银 / 黄金 / 彩钻和“该阶梯前 X% 门槛”只表示本地图鉴门槛位置，不是全球用户稀有度。首次打开只建立本设备观察基线，后续新快照才会提示新观察到的成就；完整图鉴继续支持搜索、筛选、分类折叠和键盘可访问详情。
  • Token 星云：以小时、模型和缓存构造 SVG 数据深空，可单独收藏。
  • 模块开关：按需隐藏作息、数据可信度、项目透镜、趣味、流光图、生物、成就等模块，并在 localStorage 记忆；原生复选框支持键盘操作。

分享前的隐私检查

原始 Dashboard 不只是匿名统计图out/dashboard.html 会嵌入完整日级项目与会话聚合实体，而不只是页面最终显示的 Top：项目实体可保留完整 cwd，会话实体与回放会保留会话标识，并可能采用本地 sidecar 摘要或首条提问生成标题。即使页面不联网，这些内容也会随 HTML 一起分发。

标识脱敏版本

python3 cli.py dashboard --anonymize 会在聚合进入 payload 前，用本次报告内稳定的 Project-… 与 Session-… 别名替换项目路径和会话标识，并完全跳过 sidecar 摘要和会话文本标题读取。Top、流光图和逐轮回放仍可使用匿名 identity 联动。

假名化，不是完全匿名脱敏版本仍保留精确日期、Token、小时分布、模型、来源和逐轮 Token 序列。这些信息可能形成行为指纹；自定义模型名也可能带有组织或项目语义。公开发布前仍应使用受限日期范围并检查文件。
