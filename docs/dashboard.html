Dashboard

生成合成演示核心分析探索模块导出与分享快捷键隐私
SELF-CONTAINED INTERACTIVE REPORT

离线数据宇宙

Dashboard 把聚合数据、样式、交互和内联 SVG 封装在单个 HTML 中。它不请求 CDN，也不需要本地服务器。

生成

python3 cli.py dashboard
python3 cli.py --dashboard --since 2026-01-01 --source claude

输出路径为 out/dashboard.html。位置模式与 --dashboard 开关都进入同一生成流程；传入的日期与来源筛选会写进 payload。

核心分析与联动

日 / 周 / 月粒度

标签页切换三种聚合；柱图、KPI、环形图、明细与部分模块随状态联动。

模型筛选

模型 chip 支持点击开关、双击单独查看、Alt 点击全选/清空、右键反选。

时光探针

点击柱子聚焦某一期，重算局部 KPI、作息、Top 项目与会话；Esc 返回全景。

幻影对比

在当前柱图叠加上一期轮廓与变化百分比，同时显示均值线和峰值标识。

KPI 与预测

总量、缓存命中及省量、调用次数、模型数、主力模型、环比和月末预测。

明细与模型联动

堆叠柱、模型占比、每模型趋势与图例共享悬停高亮；表格展示各期模型列。

数据探索与可视化模块

  • 当前视图胶囊：持续显示粒度、模型筛选、时光探针和幻影对比状态；可恢复全景，或复制只包含非敏感 UI 状态的视图链接。
  • 数据气候与数据侦探：根据近况、缓存、夜间比例和峰值生成本地规则描述，不调用 AI。
  • 5 小时计费窗口与近 14 天：展示生成时刻前六个小时桶和每日迷你趋势。
  • 作息时钟与作息织锦：24 小时径向分布，以及 14 天 × 24 小时时间纹理；织锦格可直接回看某日。
  • 趣味换算与今日运势：将总量映射到文字量级，并按本地统计生成娱乐性指标。
  • Token 流光图：按真实聚合展示项目 → 模型 → 会话的 Token 流向；光带宽度对应 Token 量，悬停或键盘聚焦可追踪链路，项目和模型可锁定，会话可进入逐轮回放，当前视图可保存为 SVG。
  • Token 生物：由总量、模型、项目、缓存与作息塑形，可保存为 SVG。
  • 柱图竞赛：按日播放模型累计 token 排名变化。
  • 成就图鉴：由多类统计阈值生成大量分级与隐藏成就，支持搜索、筛选和分类折叠。
  • Token 星云：以小时、模型和缓存构造 SVG 数据深空，可单独收藏。
  • 模块开关：按需隐藏作息、趣味、流光图、生物、成就等模块，并在 localStorage 记忆。

导出与分享

操作内容
导出 CSV当前粒度、当前模型筛选和明细数据。
导出 Markdown当前明细表与本地生成说明。
保存 Token 流光图 / 生物 / 星云导出当前视图对应的独立 SVG。
复制当前视图链接记录粒度、模型名、日期焦点、幻影对比和主题；不写入 cwd、会话标识或 Token 明细。
Token 护照 / 收据将汇总指标生成独立分享卡 HTML。

快捷键与命令面板

快捷键动作
1 / 2 / 3按日 / 按周 / 按月
T自动、亮色、暗色主题轮换
E导出 CSV
?打开 Dashboard 内置的快捷键与隐藏操作帮助。
Cmd/Ctrl K打开命令面板；可执行粒度、主题、视图链接、导出、模块等操作，也可搜索当前数据指令。
Esc退出时光探针，或关闭命令面板 / 弹层。

分享前的隐私检查

Dashboard 不只是匿名统计图当前实现会为 Top 项目保留完整 cwd，用于标题提示；会话排行和回放会保留会话标识，并可能采用本地 sidecar 摘要或首条提问生成标题。即使页面不联网，这些内容也会随 HTML 一起分发。公开前请逐项检查或仅分享重新制作的匿名截图/合成示例。
